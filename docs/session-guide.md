# Session setup and capability notes

[← Return to the class guide](../START-HERE.md)

## Interview first

Open an empty local Codex project with file editing permitted, or a fresh Work workspace with accessible file tools. Prompt 01 asks questions and creates brand/context.md and AGENTS.md. Use the prepared interview answer card for a consistent Copper Cup demonstration. Inspect the facts and Current campaign section before continuing.

Markdown is a text format with headings. The project instructions govern source reading, routing, output paths, and human review within the app's permissions. In local Codex, begin a fresh project chat after saving AGENTS.md. In Work, attach the files and explicitly request that they be read. Ask for downloadable files if file creation is absent.

## Skills and agent definitions

Prompt 02 creates a SKILL.md with name and description metadata under .agents/skills. Ask the assignment to read it explicitly and inspect it if discovery is unavailable. Prompt 03 creates six Markdown role cards and optional local .codex/agents/*.toml definitions using name, description, and developer_instructions. Model settings and permissions inherit from the parent. Refresh or begin a new project chat if local definitions are absent.

A role definition describes a job. An explicit assignment starts an agent task when the client supports delegation. Inspect task activity, actual file paths, source checks, and the next decision. Preserve the sequential role-based label if separate delegation is unavailable.

## Connected demonstrations in this session

Prompt 07 uses Dot or voice with appropriate computer or app access and returns written task results. Local files require the connected computer to remain available. Prompt 08 saves an owner-only Page or a structured document fallback from attached sources. Prompt 09 produces one brief and proposes bounded schedules, leaving them disabled.

These capabilities depend on account availability, current interfaces, and permissions. Use labeled prepared captures and document fallbacks when needed. The class introduces all ten prompts within one hour, with resource files available for independent reference. Inspect account usage while rehearsing subagent tasks and connected tools.
