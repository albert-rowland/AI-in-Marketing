## Keep the role separate from the assignment

For Copper Cup, the Growth Strategist reads brand context, the campaign brief, and synthetic data. Its lasting role permits draft analysis and test proposals. A campaign assignment supplies the current audience, offer, deliverables, and deadline. State the permitted actions and completion evidence before starting the task.

## Name the action before granting access

Drafting six posts inside a project uses a different permission scope from writing calendar entries or publishing them. Name the connected account, calendar, fields, message, audience, and spending limit when relevant. Reversible actions can still expose private information, so include privacy and audience in the approval decision.

## Repair the process and retest

Observe a draft, repair the instruction or handoff behind a failure, then test a different campaign case. Preserve the approved source files and use temporary test variations. A missing shipping price should produce a stated gap. An unsupported health claim should remain pending source evidence. Track accepted results, human corrections, review loops, elapsed time, and cost when available.

## Review each expansion separately

Observation, preparation, and awaiting review describe task participation. Scheduling adds a trigger, while coordination adds routing. Approve those capabilities separately and retain the publishing boundary. Repeated accepted results, correct escalation, a pause or undo path, and an identified owner support a review decision. Fixed run counts provide no reliability guarantee. Reduce access after quality failures, changed connections, or recurring manual corrections.
