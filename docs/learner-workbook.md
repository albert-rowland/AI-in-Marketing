## Build Your AI Marketing Team with Agents

ONE 60-MINUTE SESSION

Interview AI to create two foundation files. Create a skill, define six roles, and coordinate a fictional marketing campaign.

## Troubleshooting and human decisions

| If this happens | Next action |
| --- | --- |
| A file is missing | Return to the creating prompt and inspect the saved path. |
| Project guidance is absent | Begin a fresh local chat, or attach and explicitly read AGENTS.md in Work. |
| A skill is absent | Inspect SKILL.md metadata and request explicit reading. |
| A local role is absent | Inspect the TOML fields and refresh the project chat. |
| Delegation is unavailable | Use and label a sequential role-based draft. |
| Dot, Pages, or routines are absent | Use the prepared capture or structured document fallback. |
| A claim lacks a source | Remove the claim or request evidence before proceeding. |
| A task finishes without a checked artifact | Open the saved file and complete its source review. |

Draft preparation and a checked result leave external actions pending human decisions. Review the destination, audience, source version, data behavior, account usage, and ability to stop the task before authorizing a send, schedule, publication, image-generation charge, or launch.
