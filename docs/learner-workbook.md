## Understand the team

### Workbook page 4

| Term | Meaning in this course |
| --- | --- |
| Prompt | A request that names the goal, inputs, outputs, and review boundary. |
| Skill | A repeatable process stored in a SKILL.md file. Tools and permissions enable its execution. |
| Agent | A specialist assigned a task, sources, output, and review criteria. |
| Dot | Your personalized coordinator connected to permitted computers and apps. |
| Marketing Team Lead | The role that assigns tasks and reconciles the final package. |

Six roles share the campaign

| Role | Responsibility |
| --- | --- |
| Marketing Team Lead | Intake, delegation, reconciliation, final handoff. |
| Growth Strategist | Audience hypothesis, launch strategy, bounded experiment. |
| Content Creator | Social copy and brewing-guide copy. |
| Creative Designer | Artwork, visual briefs, image prompts, alt text. |
| Website Designer | Offer page and local guide-download page. |
| Growth Analyst | Metric calculations, limitations, test findings. |

A role card describes responsibilities. An explicit delegation request starts a specialist task. In local Codex, project definitions live in .codex/agents/. In Work, attach the Markdown role and request delegation with those instructions.

Use the correct denominator

CTR = clicks / impressions x 100. Lead conversion = leads / landing visits x 100. Calculate CPL by dividing spending by leads. Cost per order = spend / orders.

Report an undefined result when a denominator equals zero. Attribute orders consistently before comparing purchase costs. Revenue, profit, and ROAS require additional data.
