## Prompt 07 · Coordinate through Onigiri and voice

**Inputs**
`AGENTS.md`, `brand/context.md`, `campaigns/discovery-box/coordinated-01/handoff.md`

[Copy the full prompt](../prompts/07-coordinate-through-onigiri-and-voice.txt)

```text
Use Onigiri, my Personalized ChatGPT Dot, to coordinate the prepared Copper Cup project. Read AGENTS.md, brand/context.md, and campaigns/discovery-box/coordinated-01/handoff.md. Confirm the project path and available computer or app connection. Start a separate local Codex task or an available Work task with the attached sources to prepare the next draft revision. If I give the request through voice, leave a written task reference and result in this conversation.
Return the task link, current status, saved output path, source checks, and pending human decision. After completion, inspect the file against the context before reporting a checked result. Explain that ending a call can leave assigned tasks running, and identify the available task-activity controls. If Dot, voice, task creation, or computer access is unavailable, explain the gap and return a clearly labeled text draft for the instructor to demonstrate.
Keep this classroom task inside the selected project. Prepare draft files only. Hold external sends, publication, scheduling, spending, deletion, and permission changes for a separate human decision. If file tools are unavailable, return downloadable files or full copyable text and name the missing file access. Report saved files separately from proposals.
```

**Expected result**
`A written task reference, status, and checked revision handoff`.

**Check before continuing**
Open the written result after the call. Verify its sources, output path, and pending decision.

Limit alerts to a changed offer, deadline risk, missing input, or decision awaiting review. Explain account usage and controls for pausing future schedules and inspecting active delegated tasks. Keep both schedules disabled and wait for a separate activation decision.
Keep this classroom task inside the selected project. Prepare draft files only. Hold external sends, publication, scheduling, spending, deletion, and permission changes for a separate human decision. If file tools are unavailable, provide the full named files as downloadable files or copyable text and explain how I can save them. Report actual saved files separately from proposed files.

`One-time marketing brief and two disabled schedule proposals`.

**Check before continuing**
Identify the next human decision, source limits, time zone, end date, destination, and disabled status.
