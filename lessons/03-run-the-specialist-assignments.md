## Prompt 04 · Assign the Growth Strategist

**Inputs**
`AGENTS.md`, `brand/context.md`, `agents/growth_strategist.md`

[Copy the full prompt](../prompts/04-assign-the-growth-strategist.txt)

```text
Read AGENTS.md and agents/growth_strategist.md. Explicitly start the Growth Strategist assignment using brand/context.md and the Current campaign section in brand/context.md. Propose three audience-specific ad angles, recommend one, and describe one testable hypothesis. Use only the supplied fictional facts and label audience reasoning as a hypothesis. Save campaigns/discovery-box/run-01/strategy.md with the source paths, angle comparison, chosen direction, and next handoff to the Content Creator. Report the supported offer and the questions a human should review before continuing.
Use a supported subagent workflow for this assignment. In local Codex use the named custom agent if available, or pass the complete role card to a supported worker. In Work explicitly delegate with the role instructions and accessible project files. If subagents are unavailable, label the result a sequential role-based draft and explain that fallback. Return the visible task reference when available, actual execution mode, output path, source check, and missing inputs. A saved role card alone is not evidence that a separate agent ran.
Keep this classroom task inside the selected project. Prepare draft files only. Hold external sends, publication, scheduling, spending, deletion, and permission changes for a separate human decision. If file tools are unavailable, provide the full named files as downloadable files or copyable text and explain how I can save them. Report actual saved files separately from proposed files.
```

**Expected result**
`campaigns/discovery-box/run-01/strategy.md`.

**Check before continuing**
Inspect the task activity or fallback label, then find the chosen angle, supporting facts, and next owner.

## Prompt 05 · Create copy and visual direction

**Inputs**
`AGENTS.md`, `brand/context.md`, `.agents/skills/albert-copper-cup-ad-creative/SKILL.md`, `agents/content_creator.md`, `agents/creative_designer.md`, `campaigns/discovery-box/run-01/strategy.md`

[Copy the full prompt](../prompts/05-create-copy-and-visual-direction.txt)

```text
Read AGENTS.md, brand/context.md including Current campaign, the saved campaigns/discovery-box/run-01/strategy.md, and the ad skill. Explicitly assign the Content Creator using agents/content_creator.md to draft three Instagram copy options. Each option needs a headline, body, CTA, audience rationale, and source-backed product claims. Save campaigns/discovery-box/run-01/ad-copy.md and choose one option for design.
Wait for the copy file, then explicitly assign the Creative Designer using agents/creative_designer.md. Read that copy, the chosen strategy, context, and skill. Save visual-brief.md and image-prompts.md in the same run-01 folder. Include square composition, palette, readable text placement, accurate product count, and planned alt text. Keep image generation as a separate tool decision. Label planned alt text pending image inspection.
Check three 100 g bags, USD 29, USD 5 shipping, and Explore the Discovery Box against the context. Show the copy-to-design handoff and both task references or sequential fallback labels. Preserve the supported offer if the interview changed other campaign details.
Use explicit subagent assignments when supported. Use the named local Codex role or pass its complete Markdown instructions to an available worker. In Work, supply accessible files and explicitly delegate. Return actual task activity or references and output paths. If delegation is unavailable, label the result a sequential role-based draft. A role definition alone is not an agent execution receipt.
Keep this classroom task inside the selected project. Prepare draft files only. Hold external sends, publication, scheduling, spending, deletion, and permission changes for a separate human decision. If file tools are unavailable, return downloadable files or full copyable text and name the missing file access. Report saved files separately from proposals.
```

**Expected result**
`campaigns/discovery-box/run-01/ad-copy.md`, `campaigns/discovery-box/run-01/visual-brief.md`, `campaigns/discovery-box/run-01/image-prompts.md`.

**Check before continuing**
Inspect the copy first, then the design file that consumed it. Trace a product claim and distinguish planned artwork from a generated image.
