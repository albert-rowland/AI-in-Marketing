# Discovery Box Strategy

Fictional campaign recommendation for review.

## Recommendation
Test roast discovery against a morning-routine angle using the shared offer. Keep product details, price, shipping, and destination constant. Set audience targeting, duration, attribution, and budget with the reviewer before launch.

## Evidence
Synthetic data shows a USD 16.67 cost per order for the Discovery Box row, with USD 22.22 for the brew guide and USD 37.50 for the desk ritual. Guide campaigns show a 20% lead conversion rate. Those outcomes differ, so select the campaign objective before comparing them. The data lacks randomized assignment and supports a new test hypothesis rather than proof.

## Deliverables and review
Prepare three ad concepts, a responsive offer page, six social posts, and a draft schedule. Review claims, offer consistency, readability, alt text, mobile layout, and links. Approval of the draft remains separate from approval to spend, schedule, or deploy.
