# Troubleshooting

## Dot is absent
Check plan, region, rollout, app update, and administrator access against the current official guide. Use the prepared Dot handoff example during class and run the ad exercise through an available project chat. Recheck eligibility before the next session.

## Skills are absent
Confirm that ZIP extraction preserved .agents/skills/ and each SKILL.md. Open course-files as the primary local project folder. Ask the app to inspect the paths and refresh its skill discovery. In Work Cloud, attach the skill file and explicitly ask it to follow the supplied process if local discovery is unavailable. A skill file is a recipe, while tools and account permissions enable execution.

## Agent roles are absent
Local Codex reads the documented TOML definitions from .codex/agents/. In Work, attach the Markdown role card and ask for explicit specialist delegation. Role cards describe responsibilities and do not start runs by themselves. Use an available model and inherit its settings.

## Images take too long
Open the rehearsal ads and explain their prompts. Learners can complete the text and visual brief within the exercise time box.

## Slack or Notion is unavailable
Check the account connection and permitted destination. Demonstrate the handoff prompt in ChatGPT and show the supplied schedule CSV. A CSV remains a draft schedule until a connected-calendar write succeeds and a readback confirms it.

## Download form fails
Serve the course-files root and confirm the relative PDF path. Enter the fictional classroom address learner@example.com. Verify a malformed address blocks submission and a valid fictional address reveals the PDF link. A browser demo needs a production data and delivery integration before collecting leads.

## Sites deployment is unavailable
Keep the local preview and use prompt 16 to prepare the integration and deployment plan. Obtain approval of destination, visibility, data behavior, and rollback before any launch.
