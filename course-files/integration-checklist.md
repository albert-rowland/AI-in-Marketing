# Production Integration Checklist

## Source and approval
Confirm the approved offer, site version, destination, visibility, owner, and rollback approach. Review the deployment proposal before launching.

## Lead capture
Choose a permitted CRM or database, define its field schema, and review privacy and consent requirements. Add server-side validation, spam controls, retention, and deletion procedures appropriate to the chosen system. Define email delivery and failure handling. Keep credentials outside shared source files.

## Measurement and checks
Define page visits, submitted leads, valid leads, and attributed orders with distinct denominators. Test success, invalid input, duplicate requests, delivery failure, and mobile use. Verify stored data and the delivered PDF after an approved deployment. The classroom form validates input and reveals a file link without these production integrations.
