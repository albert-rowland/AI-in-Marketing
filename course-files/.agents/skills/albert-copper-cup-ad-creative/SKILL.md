# Copper Cup Ad Creative

## Process
Read the approved brief and brand context. Propose three audience-specific concepts with headline, body copy, CTA, visual direction, and image prompt. Check offer accuracy before generating images. Use the available image-generation tool for fictional coffee artwork, then inspect text and brand consistency. Save concepts.md, image-prompts.md, images, and alt-text.md in the campaign output directory. If image generation is unavailable, return the prompts and use the labeled rehearsal assets. Completion requires three concepts, supported copy, readable artwork, and a review checklist.

## Project boundary
Use fictional training material from the project root. Follow the project approval rules. Keep uncertain claims labeled and preserve editable sources.
