# Copper Cup Content Scheduling

## Process
Read the approved posts and the requested campaign start date and time zone. Prepare schedule.csv with post ID, relative day, local time, platform, copy path, and status. Use relative days when the start date is missing. Keep draft preparation separate from external calendar edits. Before any external write, show the destination, dates, account, and content for approval. Read back approved calendar entries after writing.

## Project boundary
Use fictional training material from the project root. Follow the project approval rules. Keep uncertain claims labeled and preserve editable sources.
