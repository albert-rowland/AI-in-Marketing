# Copper Cup Website Builder

## Process
Read the approved brief, brand context, and design-references.md. Produce a responsive page with a clear offer and CTA. Keep source files and assets together. For the classroom download demo, validate a fictional email address in the browser, display the guide link, and keep the address only in page memory. Test keyboard use, mobile layout, asset paths, and PDF delivery. Report the limits before proposing a production integration. Default to a local preview and request approval for deployment or active lead collection.

## Project boundary
Use fictional training material from the project root. Follow the project approval rules. Keep uncertain claims labeled and preserve editable sources.
