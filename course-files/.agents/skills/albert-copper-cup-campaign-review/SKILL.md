# Copper Cup Campaign Review

## Process
Read the brief and every deliverable. Compare prices, shipping, audience, CTA wording, factual claims, asset paths, alt text, and measurement definitions. Test local page behavior and inspect PDFs. Save review-checklist.md with pass, revise, or blocked for each criterion. Identify remaining integration gaps. Return the package only when defects are fixed or clearly assigned to a review decision.

## Project boundary
Use fictional training material from the project root. Follow the project approval rules. Keep uncertain claims labeled and preserve editable sources.
